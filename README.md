# Bank-Customer-Churn-Prediction

## Project Overview
This project analyzes bank customer data to identify customers who are
likely to churn and explores the key factors associated with customer
attrition.

## Dataset
The dataset contains 10,127 customer records with demographic,
financial, account, and transaction-related attributes.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Machine Learning

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Categorical feature encoding
4. Exploratory data analysis
5. Train-test split
6. Feature scaling
7. Random Forest model development
8. Hyperparameter tuning using GridSearchCV
9. Model evaluation using ROC-AUC and classification metrics
10. Feature importance analysis

## Machine Learning Model
A Random Forest Classifier was used to predict whether a customer
would remain with the bank or churn. GridSearchCV with cross-validation
was used for hyperparameter tuning.

## Key Insights
Transaction activity, account usage, and customer engagement were
important factors in understanding customer attrition.
